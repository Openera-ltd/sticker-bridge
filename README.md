# Sticker Bridge

Send a TikTok sticker to **@stickerbridge**, and it appears in a WhatsApp sticker pack automatically.

| Folder | What |
| --- | --- |
| [`apk/`](apk/) | The Android app (Kotlin, Jetpack Compose) |
| [`backend/`](backend/) | Everything on Cloudflare: the API at `api.sticker.openera.tech`, database, file storage and the @stickerbridge bot |

Download the app: https://api.sticker.openera.tech/download
